# Програмний проєкт 1 — задача 3

Програма генерує випадкові цілі числа із заданими частотами та перевіряє, наскільки отримані частоти відповідають заданим.

Стандарт: **C++23**. Компілятор: Apple Clang 17 (`-std=c++23`).

## Формат вхідного файлу

Числа можна розділяти пробілами або переходами на новий рядок.

```text
n              кількість чисел, які треба згенерувати (натуральне)
k              кількість різних вхідних чисел (натуральне)
v1 v2 ... vk   самі числа (цілі та різні)
f1 f2 ... fk   їх частоти (натуральні)
```

Приклад:

```text
100000
3
1 2 3
1 2 2
```

Для цього прикладу очікувані частки дорівнюють `1/5`, `2/5` і `2/5`.

## Обробка помилок

Програма перевіряє:

- чи вдалося відкрити файл;
- чи всі потрібні значення присутні у файлі;
- чи `n`, `k` та частоти є додатними;
- чи вхідні числа не повторюються;
- чи немає зайвих даних після частот;
- чи не переповнюється сума частот.

## Збирання і запуск

Приклад збирання через Apple Clang 17:

```text
clang++ -std=c++23 main.cpp InputReader.cpp PrefixSumGenerator.cpp DiscreteGenerator.cpp Report.cpp -o weighted_random
```

Ім'я вхідного файлу можна передати як аргумент командного рядка. Якщо аргумент не передано, програма запитає ім'я файлу з клавіатури.

```text
./weighted_random input.txt
```

## Результат

Для кожного числа виводяться задана та отримана частоти, а також їх розбіжність. Програма окремо показує результат власного алгоритму на основі накопичених сум і результат `std::discrete_distribution`, після чого виводить найбільшу розбіжність для кожного генератора.

## Структура проєкту

- `Item.h` — число, його вага та оператор `<=>`;
- `InputReader.*` — читання і перевірка вхідного файлу;
- `PrefixSumGenerator.*` — власний функціональний об'єкт;
- `DiscreteGenerator.*` — функціональний об'єкт на основі `std::discrete_distribution`;
- `Statistics.h` — проведення експерименту та підрахунок частот;
- `Report.*` — виведення результатів;
- `main.cpp` — запуск програми.
